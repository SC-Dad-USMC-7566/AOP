# AOP Gate — Do the Per-Mechanism Ceilings Predict the Worked Cases? (PRE-REGISTRATION)

**Status: pre-registration. Exits frozen before computation. Two exits only: GO / NULL.**
_Drafted 2026-07-16. Test #3 of the substitutability follow-ons. If each persistence mechanism
has a ceiling, the five canon worked cases — each dominated by one mechanism — should sit
*consistently* with those ceilings: a mechanism-dominated persister should not be more persistent
than its dominant mechanism's ceiling allows without help from a second mechanism. This gate is a
consistency test of the ceiling structure against the cases the framework already commits to._

---

## The mapping (frozen, from the canon's four-axis profiles)

Barrier↔Boundary, Flux↔Drive, Bank↔Memory. The canon's worked-case dominances:
- **crystal** — Barrier-dominated (high Boundary, near-zero Drive/Memory).
- **flame** — Flux-dominated (high Drive, negligible Memory; persists only while fed).
- **spore** — Bank-dominated (deep stored structure, near-zero Drive).
- **bound atom** — minimal/Barrier (low-edge admitted case).
- **star** — high Drive AND high Integration (mixed, gravitationally bound).

## The prediction under test (frozen)

From the ceiling structure: a **pure-Flux** persister and a **pure-Bank** persister each have a
hard persistence ceiling (they cannot be pinned arbitrarily deep by throughput or reset alone),
while a **Barrier**-dominated persister can be arbitrarily persistent. Mapped to the cases:

- The **flame** (pure Flux) should be the framework's *least durable* case — marginal, un-
  improvable by more throughput, consistent with sitting at/below a Flux ceiling.
- The **crystal** (pure Barrier) should be the *most durable* — consistent with the unbounded
  wall.
- The **spore** presents the sharp test. Spores are empirically near-maximally persistent
  (Bacillus spores viable over 10³–10⁶ yr). If the spore were **pure Bank**, the Bank ceiling
  would forbid that. So the prediction is: **the spore is NOT pure Bank — it must carry a
  load-bearing Barrier** (the coat/cortex, a genuine wall), so its durability comes from
  Barrier, not Bank. The canon's own account (spore = deep Memory) would then be incomplete on
  the *persistence* axis, even if right on the Memory axis.

## GO requires (frozen)

1. Rank order of the cases' persistence is consistent with the ceiling ordering: crystal (Barrier)
   ≥ spore ≥ flame (Flux), with the flame the least durable.
2. The spore's empirical near-immortality is attributable to a **Barrier** contribution (a
   physical wall), not to Bank alone — i.e. removing the wall (coat) collapses spore persistence,
   consistent with Bank alone being ceiling-bounded. Tested on the minimal model by checking:
   does a Bank-only configuration cap well below a Barrier+Bank configuration at matched Memory?
3. No case is more persistent than its dominant mechanism's ceiling allows without a second
   mechanism present.

## NULL requires (any one, frozen)

- The rank order is violated (e.g. the flame out-persists the crystal in the framework's terms).
- A pure-Bank configuration reaches arbitrary persistence on the model (no ceiling), so the
  spore argument is moot and the ceiling structure makes no worked-case prediction.
- The spore's durability cannot be attributed to Barrier within the framework's own account
  (the mapping breaks).

## Why both exits are reachable

GO reachable: the qualitative durability ranking (crystal > spore > flame) is plausible and the
Barrier-rescue of the spore is a real, checkable claim on the model. NULL reachable: if
Bank has no ceiling the whole prediction dissolves; if the flame is somehow scored most durable
the mapping is wrong.

## Decision rule

GO only if all three GO criteria hold. NULL if any NULL criterion holds. No third exit. This gate
is explicitly a **consistency test**, not a measurement of real crystals/flames/spores — it asks
whether the ceiling structure is coherent with the canon's committed worked-case profiles.

## What a result licenses

- GO: the ceiling structure makes a correct, non-trivial prediction about the worked cases —
  notably that the spore's durability is Barrier-borne, sharpening the canon's spore account.
- NULL: the ceiling structure does not organize the worked cases; it stays a statement about the
  abstract model only.
