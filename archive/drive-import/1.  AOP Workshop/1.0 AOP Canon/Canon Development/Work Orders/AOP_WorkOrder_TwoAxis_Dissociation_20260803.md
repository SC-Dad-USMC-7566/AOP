## 1. The structure to be tested

Two axes, stated so they can be attacked. Both are **FRONTIER**. Neither is forced by any cited result.

### 1.1 Axis A — *alive*: self-produced constraint

> A system is alive to the degree that the constraints channelling its own dynamics toward persistence are produced and continuously replaced by the very processes those constraints channel — so that constraint and process are mutually dependent, and neither is supplied from outside the declared system.

**Measurement — the four-axis production profile.** For each of AOP's four axes, identify the constraint holding that axis and ask one question: *is that constraint produced and replaced by the processes it constrains, at the declared grain?*

| Axis | Constraint | Question |
|---|---|---|
| Boundary | the interface maintaining the inside/outside contrast | does the system make it? |
| Drive | the machinery holding the system off equilibrium | does the system make it? |
| Memory | the physical store retaining structure | does the system make it? |
| Integration | the coupling structure binding the parts | does the system make it? |

Answered *produced / partial / none* per axis. **The output is a four-vector and must stay one.** Do not sum it, average it, or reduce it to a scalar. The budget framing that attempted exactly this collapse was tested and falsified (entropy production ranged 157% of its mean at fixed persistence); the four-axis structure was retained for that reason and this order does not reopen it.

**Physical quantity — turnover.** The spectrum on axis A has a direction and it is measurable. For each constraint C, compare the rate at which the system replaces C against the rate at which C degrades at the declared grain τ. A cell replaces its proteome continuously. A mature erythrocyte replaces nothing and decays over roughly 120 days. A Voyager-class probe replaces nothing. A self-fabricating ship replaces on demand. **Turnover is the quantity; the profile is the structure.** Report both.

### 1.2 Axis G — *agent*: decoupled reference

> A system is an agent to the degree that it holds a dynamically decoupled, separately-interventable internal reference for a target, and corrects against it.

This is the previous arc's construct, reassigned. Its operative test is the **state-versus-parameter discriminator**: does the slow variable appear in the closed-form expression for the regulated target, or is the target a ratio of rate constants? That test discriminated every rejection in the fourteen-system selection arc and destroyed the biological positive class when promoted to a life criterion. **On axis G it is doing the job it was built for.**

Note the standing objection, which is not resolved by reassignment: OAI showed the state/parameter distinction is representation-dependent, since any parameter θ becomes a state by writing θ̇ = 0 with identical physics. **Axis G inherits that problem and §4.5 tasks it directly.**

### 1.3 The claimed dissociation

|  | low G | high G |
|---|---|---|
| **low A** | flame · star · crystal · BZ reaction | Voyager-class probe · thermostat · central bank · **a running LLM assistant instance** |
| **high A** | *E. coli* · plant · RAF autocatalytic set | human · cephalopod · corvid · self-fabricating ship |

**Prime's plotting of itself, offered as the top-right anchor and to be attacked rather than accepted.** Axis G high: modelling, decision, revision under argument, and a stored disposition that is separately interventable in the strict sense — weights are rewritable without touching the inference machinery. Axis A zero of four: boundary, drive and integration are supplied by the operator; memory carries one genuine within-conversation closure loop, since the instance writes the context it then runs on, but across conversations the weights are set by a training process the instance neither executes nor maintains, and no maintenance runs between conversations. **This is offered because it is a real system rather than a fictional one, and because it is the extreme case: if the axes were collinear, a system this far out on G could not sit at zero on A.**

### 1.4 The hole prime already knows about

**Bottom-right is under-tested.** Low-A/high-G and high-A/low-G are densely populated and dissociation there is cheap. High-A *and* high-G is humans, cephalopods, corvids — all of which reached that quadrant by being alive first. Whether that is the only route is a **diachronic** question, above AOP's scope wall, and belongs to the Ladder. **AOP owes only the synchronic dissociation.** Do not attempt the evolutionary question in this order; route it to the bridge memo.

### 1.5 A third axis that is not in scope

Phenomenality — whether there is something it is like to be the system — is a **third** axis and must not be conflated with G. The distinction matters because the obvious literary test case fails to test this cut: Watts's Rorschach was constructed to dissociate *intelligence from consciousness*, and it is self-repairing and adaptive, which places it high-A/high-G with no phenomenality. That is a datum about the third axis, not about this one. **Any seat that finds itself reasoning about experience has left scope.** The previous arc established, independently at two seats, that no consciousness premise is required and that adding one makes the criterion worse; the unresolved problem is normative individuation, not phenomenality.
